How it holds up

Four decisions that make it portable

Each one replaces something that broke in the system this replaced.

$0.00

Indexing costs nothing

Retrieval is lexical, not embeddings. It runs offline with no network call, so your key is only ever spent on reasoning. Term positions are exact, which is what lets a span resolve to real character offsets instead of a rough neighbourhood.

No dependencies

Node built-ins only. There is no npm install, no build step, and nothing to break on a machine that is not yours.

One key, nothing else

Paste an OpenRouter or Anthropic key. The provider is inferred from its shape, so you never declare one.

Phases refuse, they do not ask

A research run moves through eight phases, and each writes a durable artifact before the next may start. The ordering is a property of the system rather than an instruction a model is trusted to follow, so a crash resumes instead of restarting and any phase can be re-run alone.

Install

Requires Node 18 or newer and one API key. Nothing else.

Add the plugin
claude plugin marketplace add janmejai2002/stratx
claude plugin install stratx@stratx
Point it at your sources
stratx init
stratx config set-key   # input hidden
stratx ingest ./docs
stratx ask "your question"

stratx doctor reports exactly what is missing at any point. The workspace lives in .stratx/ inside your project, gitignored by default, and holds the corpus, the spans, every run and an append-only cost ledger.
